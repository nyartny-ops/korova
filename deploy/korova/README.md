# Korova VPN — установка

Korova — форк 3x-ui v3 со своим слоем: Telegram-бот с оплатой звёздами, промокоды и приглашения, тарифы по числу устройств, автоматические каскады и новая панель. Собирает её GitHub, серверы только скачивают готовый архив (~40 МБ), как оригинальная 3x-ui.

## 1. Один раз: код на GitHub

1. Зарегистрируйся на github.com и установи [GitHub Desktop](https://desktop.github.com/).
2. Распакуй `korova.zip` в папку, например `~/Documents/korova`.
3. GitHub Desktop → **File → Add local repository** → выбери папку `korova`. Он предложит создать репозиторий — **create a repository**, затем **Publish repository**.
4. Сними галочку **Keep this code private** (секретов в коде нет: токен бота и пароли хранятся только на сервере). Нажми **Publish**.
5. На сайте репозитория открой вкладку **Actions**. Через ~10 минут сборка «Korova build» станет зелёной, а в **Releases** появится `korova-latest`.

Если Actions спрашивает разрешение запускать сборки — нажми **I understand… enable**.

## 2. Основной сервер

```bash
ssh root@144.31.251.157
systemctl disable --now nginx          # если nginx не нужен: порты 80 и 443 нужны панели
bash <(curl -fsSL https://github.com/ТВОЙ_НИК/korova/releases/download/korova-latest/korova.sh) install
```

Скрипт спросит домены, токен бота и админов, за минуту поставит панель и HTTPS и покажет адрес, логин и пароль. Повторно посмотреть их: `korova info`.

Порт 443 на основном сервере занят панелью и подписками: VPN на нём ставь на 8443, а лучше держи VPN на узлах.

## 3. Первый запуск в панели

Экран «Обзор» покажет 4 шага: создать подключение во «Входящих» (VLESS + Reality), отметить его в «Бот и доступ», проверить бота и тарифы. Режим по умолчанию — «по приглашениям», пригласить человека — кнопка «Пригласить человека».

## 4. Дополнительный сервер (узел)

1. В панели открой **Серверы и каскады → Подключить сервер** и скопируй команду установки.
2. Зайди на новый сервер (`ssh root@IP`) и выполни её. Через минуту в конце появится ключ `korova-node:…`.
3. Вставь ключ в поле «Ключ узла» и нажми **Подключить**. Адрес, порт, путь, API-ключ и сертификат подтянутся сами.
4. Создай на узле подключение во «Входящих» (выбери узел) и отметь его в «Бот и доступ».

Если панель пишет, что не достучалась до узла, — открой в панели хостинга узла входящие TCP 2053 и 443. Потерял ключ — `korova token` на узле.

## 5. Каскад РУ → зарубеж

Подключи оба сервера как узлы, создай подключение-выход за границей и подключение-вход в РФ, затем **Серверы и каскады → Новый каскад**. Подписчикам отмечай только вход.

## Обновление

Изменения в коде → GitHub Desktop → **Commit** → **Push** → через ~10 минут сборка готова. На каждом сервере:

```bash
korova update
```

Кнопку «Обновить панель» в веб-интерфейсе не нажимай: она поставит оригинальную 3x-ui поверх Korova.

## Полезное

- Адрес, логин, пароль: `korova info`
- Новый API-ключ узла: `korova token`
- Логи: `journalctl -u x-ui -f`
- Перезапуск: `systemctl restart x-ui`
- База: `/etc/x-ui`, настройки установки: `/etc/default/x-ui`
